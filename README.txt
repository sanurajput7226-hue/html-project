Manufacturing Production Planning System
-----------------------------------------
How to run: unzip and double-click index.html (no installation needed).

Files:
  index.html - page structure (tables, form, cards)
  style.css  - colours and layout
  script.js  - data (arrays) and logic

Logic:
  Progress  = stages completed / 5 * 100
  Delayed   = due date passed and order not completed
  Busy      = machine assigned to an unfinished order
  Shortage  = stock less than material needed by pending orders
